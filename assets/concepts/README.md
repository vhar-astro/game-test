# Concept art provenance

Created with built-in imagegen and inspected before corresponding model/world code.
Retained files: environments.png and objects.png. Concepts are not game screenshots.

Environment prompt: one cohesive three-panel production board. Teal Crystal Forest with
faceted trees, basalt platforms, brass mechanisms and landed silver ship; warm ochre ruins
suspended in space; cream/brass observation station with armillary and portal rings.
Stylized semi-realistic geometric forms, navigable silhouettes, curiosity and unease,
soft shadows, common mint accent, no UI/text, original economical Blender modules.

Object prompt: consistent dark-background contact sheet: cream/navy/gold helmeted explorer,
compact delta-wing landed ship, charcoal/brass guardian with orange eye, mint prism on
pedestal, resonance gauntlet with luminous ring, tapered gold-framed crystal and dark stone
portal with brass/cyan rim. Neutral rig-friendly poses, visible joints, readable three-quarter
views, bevelled geometric forms, no UI or text.

Inspection decisions: retain silhouettes and palette families, distinguish prisms with
I/II/III world markers, use opaque faceted crystal materials, rigid segmented skeletons and
reusable architecture. Built-in generation was used; no CLI/API-key fallback.
